왜 SILO인가

보안 규정 때문에 AI를 못 쓰는 현장이 많습니다

클라우드 AI는 편리하지만, 인터넷이 없거나 자료를 밖으로 보낼 수 없는 곳에서는 쓸 수 없습니다.

외부 망 접속이 금지된 곳

군부대, 항만 운영망, 발전·플랜트 제어망은 인터넷이 차단되어 있어 ChatGPT 같은 서비스를 쓸 수 없습니다.

반출할 수 없는 내부 자료

도면, 점검 기록, 내부 매뉴얼은 외부 AI에 붙여 넣는 순간 보안 규정 위반이 됩니다.

수개월 걸리는 서버 구축

사내 GPU 서버는 예산 승인, 설치 공간, 보안 심사까지 몇 달이 걸립니다. 현장 팀이 당장 쓰기엔 맞지 않습니다.

사용 방법

꺼내서 연결하면 바로 씁니다

설치할 프로그램도, 가입할 계정도 없습니다. AI 모델과 사용 화면이 모두 장비 안에 들어 있습니다.

STEP 1

전원 켜기

노트북 충전기 크기의 어댑터를 꽂으면 1~2분 안에 준비됩니다.

STEP 2

랜선 연결

노트북에 바로 연결하거나, 작은 스위치로 2~3대를 함께 연결합니다.

STEP 3

브라우저로 사용

정해진 주소로 접속하면 채팅 화면이 열립니다. 질문, 요약, 번역, 초안 작성을 바로 합니다.

보안 설계

데이터가 나갈 길을 처음부터 없앴습니다

보안 점검을 받을 때 설명하기 쉽도록 구성 자체를 단순하게 만들었습니다. 도입 기관의 점검에 필요한 구성 설명 자료도 함께 드립니다.

무선 기능 차단

기본 구성은 Wi-Fi와 Bluetooth를 끈 상태로 출고합니다. 무선 모듈을 물리적으로 떼어 내거나, 필요하면 인터넷과 분리된 장비 전용 Wi-Fi로 켜 둘 수도 있습니다.

저장 장치 전체 암호화

장비를 잃어버려도 저장된 대화와 자료를 읽을 수 없습니다.

최소 구성 Linux

AI 실행에 필요한 것 외의 서비스는 설치하지 않습니다.

기록은 장비 안에만

대화 기록은 장비에만 남고, 사용자가 직접 지울 수 있습니다.

FAQ

자주 묻는 질문

결제와 세금계산서는 어떻게 하나요?

온라인 결제는 받지 않습니다. 구매 신청 후 담당자가 견적서를 보내 드리고, 계좌이체로 결제합니다. 세금계산서를 발행하며, 기관의 구매 절차가 따로 있으면 그에 맞춰 서류를 준비합니다.

주문하면 언제 받을 수 있나요?

결제 확인 후 장비 설정과 점검을 거쳐 약 1~2주 안에 납품합니다. 수량이 많으면 일정을 따로 안내합니다.

고장 나면 어떻게 하나요?

하드웨어는 제조사 보증 기준으로 처리하고, 설정과 모델 문제는 저희가 직접 지원합니다. 자세한 지원 범위는 견적 안내 때 함께 드립니다.

ChatGPT만큼 똑똑한가요?

SILO에 들어가는 gpt-oss-20b는 ChatGPT를 만든 OpenAI가 공개한 모델로, OpenAI 발표 기준 주요 평가에서 자사 o3-mini와 비슷한 성능을 냅니다. 문서 요약, 보고서 초안, 번역, 코드 설명처럼 현장에서 매일 하는 일을 충분히 해냅니다. 여기에 인터넷 연결이 필요 없고, 사용량 요금이 없으며, 자료가 장비 밖으로 나가지 않는다는 점은 클라우드 AI가 줄 수 없는 장점입니다.

정말 외부로 아무것도 나가지 않나요?

장비는 인터넷 연결 없이 동작하도록 구성되어 있고 기본 구성은 무선 기능을 끈 상태로 출고합니다. 외부 망에 연결하지 않는 한 데이터가 나갈 경로가 없습니다. 보안 점검에 필요한 구성 설명 자료도 제공합니다.

몇 명이 함께 쓸 수 있나요?

1~3명 팀 기준으로 설계했습니다. 여러 명이 동시에 질문하면 차례로 처리되어 응답이 느려질 수 있습니다. 더 많은 인원이 필요하면 상담 때 말씀해 주세요.

응답 속도는 어느 정도인가요?

질문 길이와 붙여 넣은 문서 양에 따라 다릅니다. 짧은 질문은 몇 초 안에 답이 나오기 시작하고, 긴 문서 요약은 더 걸립니다. 구매 전에 실제 사용 화면 시연을 요청하실 수 있습니다.

모델 업데이트는 어떻게 하나요?

승인된 저장 매체로 업데이트 파일을 전달하거나, 장비를 회수해 업데이트하는 방식 중 기관 규정에 맞는 방법으로 진행합니다.

우리 내부 문서를 학습시킬 수 있나요?

모델 자체를 다시 학습시키지는 않습니다. 필요한 문서를 대화에 붙여 넣어 활용하는 방식이 기본이며, 문서 검색 기능이 필요하면 신청서에 적어 주세요.
